# Poker Field Lab

텍사스 홀덤의 내 패와 바닥패를 바꿔 보며 승률과 카드 확률을 살펴보는 한국어 웹 도구입니다.

공개 웹사이트: https://poker-field-lab.yuna3402.chatgpt.site

## 기능

- 내 패·바닥패·지정 상대 패 선택 및 한 장 삭제
- 전체 2·3·4명에 따른 단독 승리, 공동 승리, 예상 팟 지분 비교
- 플랍·턴에서 상대의 리버 최종 족보 확률과 완성 카드 예시
- 원페어·투페어를 제외한 내 최종 족보 확률과 남은 카드 평균 대비 차이
- 나와 상대의 대기 카드, 다음 카드·리버까지 출현 확률
- 시작 패 순위표와 포커 족보 안내

## 실행

별도 설치나 빌드가 없는 정적 웹사이트입니다. `docs/`를 HTTP 서버로 제공하면 됩니다. 예: `python -m http.server 8000 --directory docs` 후 `http://localhost:8000` 접속.

GitHub Pages에서는 `main` 브랜치의 `/docs` 폴더를 게시 원본으로 선택합니다.

## 계산 기준

52장 덱과 표준 홀덤 족보를 사용합니다. 쇼다운과 여러 상대 확률은 40,000회 시뮬레이션 추정입니다. 인원은 나를 포함한 전체 인원입니다. 플랍 이후 내 최종 족보, 무작위 두 장의 평균, 상대 한 명의 최종 족보는 가능한 조합을 전수 계산합니다. 여러 상대의 합집합은 첫 상대의 정확한 확률에 표본에서 추가로 관측된 상대들의 확률을 더해 추정합니다. 미지 상대 패는 남은 카드에서 균등하게 배분하며 폴드나 베팅 성향은 반영하지 않습니다. 족보 확률과 승률은 서로 다른 지표입니다.

평균은 내 패와 알려진 바닥패·지정 상대 패를 제외한 카드에서 무작위 두 장을 받는 패의 최종 족보 확률입니다. 플랍은 남은 카드에서 4장을 고른 조합, 턴은 3장, 리버는 2장을 고른 조합을 평가합니다. 홀덤은 최상의 5장을 쓰므로 미지 상대 패와 남은 보드의 구분에 관계없이 같은 최종 7장은 같은 족보가 됩니다. 프리플랍은 시뮬레이션으로 추정합니다.

족보 표는 가장 높은 최종 족보로 분류합니다. 드로의 플러시·스트레이트는 스트레이트/로열 플러시도 포함합니다. `다음 카드`는 한 장으로 해당 조합을 만드는 확률, `리버까지 카드`는 표시한 대기 카드 중 하나 이상을 받는 확률, `리버 완성`은 최종 조합 확률입니다. 상대 패를 지정하지 않았을 때 드로는 가능한 패의 예시이며 실제 상대 패를 추론한 결과가 아닙니다.

시작 패 색상표의 퍼센트는 제공된 이미지의 누적 순위 구간이며 개별 승률이 아닙니다. 원본 이미지의 산출 조건은 제공되지 않았습니다.

계산은 브라우저의 Web Worker에서 수행되며 입력 카드가 서버로 전송되지 않습니다. 화면 폰트는 Google Fonts를 사용하며, 연결이 없으면 시스템 폰트로 표시됩니다.
